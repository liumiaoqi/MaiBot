# 音乐规则生成器 — 实验总结

> 2026-08-06 实验闭环
> 环境：scripts/embedding_finetune（Windows uv，numpy）

## 实验结论（lmq 认知链）

1. **音乐是数值结构不是统计结构**：音高 = 数值（音程 = 差），时值 = 分数（比例 = 算术）
   ——"能直接计算为什么要通过概率计算"（token 化抹平数值语义，是文本的范式不是音乐的）
2. **规则即风格**：风格统一性来自生成规则（同套规则 = 同风格），不来自数据——
   找不到"1M 风格统一简谱"是因为风格本来就该从规则生成，不是从数据找
3. **规则引擎能学习**：从 ~20 首旋律归纳出可读规则（导音解决 7→6 70% / 属音解决 5→3
   / 跳进补偿 +5→-1 80% / 终止式 3-2-1）——与音乐理论吻合，21 首样本学到和声学规律
4. **规则引擎能推理**：前向链（动机发展 → 转移推理 → 跳进补偿 → 终止式收束）——
   规则组合产生新结构，不是查表复现
5. **用户喜欢 = 风格标签**：一首真心喜欢的曲子（璃月）足以提炼动机 DNA——
   `2-5→3（82%）`、`5-3→2（74%）` 的璃月琶音规则进入规则库，生成出璃月味

## 模块

| 文件 | 职责 |
|------|------|
| `rule_gen.py` | v1 理论规则生成（调式/和弦/动机/速度旋钮，纯计算） |
| `corpus.py` | 语料（12 首：民歌/古典/五声/璃月——璃月占 72%） |
| `induction.py` | 学习层：Apriori 关联归纳 + 音程规则 + 动机挖掘（可读规则输出） |
| `infer_gen.py` | 推理层：归纳规则前向链生成（4/4 v2 + 12/8 v3） |
| `jianpu_parser.py` | 简谱解析 + 渲染管线（12/8、195bpm、降八度、呼吸、力度） |
| `output/liyue_jianpu.txt` | 用户手动修改的璃月乐谱（约定格式） |

## 简谱符号约定（人机协作，全键盘可输入）

```
1-7 音高（12/8 下 = 8 分音符）  0 休止
1' 高八度  1'' 高两个八度  1''' 高三个八度  1, 低八度
1_ 时值减半（16 分）  1__ 32 分
. 或 · 附点   - 延长一拍
#4 升号   ( ) 弧线（tie 同音合并时值 / slur 连奏）
^5 上滑音   tr 颤音（装饰，时值不延长）
| || 小节线/终止线   1=E 转调
```

## 渲染定稿参数（用户验收）

- 8 分音符 = 195/分（♩=336 以 8 分音符为一拍记的修正）
- 整体降一个八度（统一高八度后的音区修正）
- 22% 音符间隙（呼吸感）+ 1/2 拍小节呼吸
- 半幅音量（归一化目标 0.5）
- 力度动态：节拍重音 ×1.25 + 音高加权
- 柔和音色：弱谐波（0.2/0.06）+ 中速衰减

## 用法

```bash
uv run python induction.py                          # 归纳规则
uv run python infer_gen.py --seed 42 --bars 8       # 4/4 生成
uv run python infer_gen.py --seed 42 --bars 16      # 12/8 生成（generate_12_8）
uv run python jianpu_parser.py --file output/xxx.txt --section part1 \
    --wav output/xxx.wav --bpm 195 --octave-shift -1   # 定稿渲染
```

## 遗留方向

- 伴奏声部（低音/和声铺底——单旋律线单薄的根源）
- 节奏归纳（时值规则——目前只归纳音高）
- 转调段解析（1=E 渲染按调转）
- tie 弧线时值合并
