## probe1：exp29 遗忘模型（granular / 振幅阻尼 / 两能级 / 复习）

### A. 三体系复现（Python 原版 · Wolfram · MATLAB）

| 模型 | MAE | 31 天留存 |
|---|---|---|
| granular（指数 + 地板） | 0.43316 | 27.48% |
| ampdamp（振幅阻尼） | 0.41652 | 20.39% |
| twolevel（S 快 + L 慢） | 0.17727 | 8.56% |
| twolevel + 复习 {1,3,7,14} | — | **1.1133**（111.33%） |

三体系数字完全一致（Wolfram 14.3 / MATLAB R2025b / 原 Python）。

### B. 符号分析 → 三个发现

#### 发现 1（主）：31 天留存只依赖复习「次数」，与「分布」无关

闭式（n = 复习次数）：

```
ret31(n) = 0.7·e^(−31/1) + (0.1 + 0.3n)·e^(−31/200)
```

（S 项在 t=31 时 ≈ 7e-14，可忽略 ⇒ 留存几乎完全由 L 的计数决定）

**验证——10 种分布给出同一个数字 1.1133：**

| 分布 | 31 天留存 |
|---|---|
| spaced {1,3,7,14} | 1.1133 |
| crammed {27,28,29,30} | 1.1133 |
| midblock {14,15,16,17} | 1.1133 |
| 随机 5 组（MATLAB） | 全部 1.1133 |

⚠️ **结论：原模型里「间隔效应」没有被建模。**
exp29 的文本「间隔复习（1/3/7/14 天）31 天留存 111.33%」应修正为：
**「复习 4 次（无论分布）把 31 天留存提到 111.33%」——起作用的是次数，不是间隔。**

**根因**：实现用「全局时钟」算曲线（`S·e^(−t/τs) + L·e^(−t/τl)`，t 从 0 起算），
复习只是把状态 S 调回 0.7、L 加 0.3；状态本身不逐时衰减（衰减只发生在曲线公式里）
⇒ S 退化为「最近一次复习的幅度」、L 退化为「复习计数器」。

#### 发现 2：交叉时间闭式

```
t* = ts·tl·ln(S0/L0)/(tl − ts)   →  1.9557 天（exp29 参数）
```

「短期态让位长期态」的特征时间短于 2 天。

#### 发现 3：长期行为有峰值（≈ τl）

定期复习（Δt = 7 天）两年：峰值 **3.304 @ t = 189 天**（≈ τl = 200）——
即使无限复习，曲线终将回落，特征时间由 τl 决定。

**相位修正预览**（若 L 的衰减改为从复习时刻起算）：
稳态 `L* = 0.3·e^(−Δt/200)/(1 − e^(−Δt/200))`

| Δt | L* |
|---|---|
| 1 d | 59.85 |
| 7 d | 8.42 |
| 30 d | 1.85 |

⇒ 频率敏感（小 Δt 指数放大），**任何「复习增益」模型都需要饱和/上限**。

**S 相位量化**：复习后 1 天，S 分量 —— 无相位重置 2.14e-7 vs 有相位重置 0.2575（差 6 个数量级）。

## 结论

1. **本次「发现」的性质 = 敏感性审计**：单点数值全部复现（8.56% / 111.33% 一个不差），
   但**扰动「分布」这个维度后发现模型对它完全不敏感**——数值对拍查不出这类问题，闭式一眼可见。
2. **对 MaiBot 记忆系统设计的启示**：
   - 要真实产生间隔效应：L 的衰减需从复习时刻起算（相位正确）+ 复习增益要有结构（∝ 当前强度 / S→L 转化）
   - 复习增益必须有饱和，否则密集复习的稳态会指数失控
3. **下一步候选**：做修正模型（相位 + 强度依赖），检查「间隔效应」能否从模型里长出来
   （预期：出现内点最优 Δt）。

## probe2：修正版遗忘模型——「间隔效应」长出来了

### 修了哪两处

1. **相位**：状态按日演化（S、L 逐日衰减 `*e^(−1/τ)`），曲线值 = S + L（状态即真实强度）——废除「全局时钟」
2. **增益结构**（对照实验）：
   - `stock`：`L += k·S`（增益 ∝ 当前短期存量）
   - `gap`：`L += k·(s0 − S)`（增益 ∝ 遗忘缺口——「提取困难度」的数学形态）

参数：s0=0.7, L0=0.1, τs=1, τl=200, k=0.5, 31 天窗口, 4 次复习。

### 结果

| 分布 | orig31 | v2-stock | v2-gap |
|---|---|---|---|
| cram {27,28,29,30} | 1.1133 | 0.7256 | 1.3434 |
| spaced {1,3,7,14} | 1.1133 | 0.2436 | 1.1651 |
| even7 {7,14,21,28} | 1.1133 | 0.1217 | **1.4289** |
| early {1,2,3,4} | 1.1133 | 0.5323 | 0.8531 |
| late {20,24,28,30} | 1.1133 | 0.4028 | **1.6458** |

**MATLAB 全枚举（C(30,4) = 27405 组）**：

| 模型 | 值域 | top1 分布 |
|---|---|---|
| orig | **只有 1 个唯一值**（全 1.1133） | —（无差别） |
| v2-stock | 0.0895 – 0.7256 | {27,28,29,30}（越晚越密） |
| v2-gap | 0.8531 – **1.6795** | **{16,21,26,30}**（间隔 5/5/4） |

### 结论

1. **「间隔效应」不是复习的自动属性——它依赖增益结构**：
   - stock 结构：越晚越密占优（无间隔效应，甚至反间隔）
   - **gap 结构：内点最优出现**——top1 {16,21,26,30} 比 cram 高 **+25%**（1.6795 vs 1.3434）
2. **最优「间隔 ≈ 4.6–5 天」有解析来源**：
   gap 增益 = `k·s0·(1 − e^(−d))`，d ≥ 5 天时增益饱和到 99%+（1% 精度要求下 d* = ln(100) ≈ 4.6）——
   最优策略 =「**每次都让增益吃满**（间隔 ≥ 4.6 天）+ **尽量靠后**（减少 L 衰减）+ **末次贴观测点**」。
   原 exp29 注释里那句「复习在 S 将尽未尽时进行」终于被数学表达了——但在修正模型里才有意义。
3. **v2 天然有界**（增益 ∝ 有界状态），不再有 probe1 里「L 无上限」的问题。
4. ⚠️ **口径警告**：v2 的绝对水平与 orig 不可直接比（增益参数 k=0.5 是随手选的、且语义已修）；
   v2 的价值是**结构演示**——回答「间隔效应需要什么结构」。

## probe3：exp31「Grover 式放大」的数学身份——其实是 softmax 温度采样

### 机制对拍（三体系逐位一致）

scores = {0.9, 0.7, 0.5, 0.3, 0.1}，`P_i = clip(s_i,0)^k / Σ`：

| k | 概率分布 |
|---|---|
| 1 | 0.36 / 0.28 / 0.20 / 0.12 / 0.04 |
| 2 | 0.490909091 / 0.296969697 / 0.151515152 / 0.054545455 / 0.006060606 |
| 8 | 0.874778507 / 0.117150015 / 0.007938127 / 0.000133330 / 2.03e-8 |

Python / Wolfram / MATLAB **逐位一致**。

### 发现 1（主）：它是一个恒等式——softmax 的温度形式

```
s^k / Σs^k  ≡  softmax(k·ln s)        差 < 1.1e-16（机器精度）
```

⇒ 「k=1 线性采样 / k=2 平方放大 / k=8 强放大」是**温度 τ = 1/k 的一条连续轴**；
**「贪心」不是独立策略——是 k→∞ 的极限点**（exp31 把轴端点当成了对照组）。

⇒ **MaiBot 意义**：目标选择器的 k 和 LLM 采样的 temperature 是**同一个数学对象**——
一个旋钮就能把「随机 → 贪心」连续滑动，两边的语言可以统一。

### 发现 2：真 Grover 与 score^k 是两个物种

| | 真 Grover | score^k |
|---|---|---|
| 公式 | `sin²((2k+1)θ)`，`sinθ = 1/√N` | 幂律锐化 |
| 行为 | **振荡、过旋**（N=5：96.8% → 53.8% → 1.1% → 73.6%） | **单调**（0.36 → 1.0） |
| 最优 | `k_opt(N) ≈ π√N/4`（N=4→1.0 / 256→12.1） | k→∞ |
| 机理 | 相位干涉（振幅层面） | 概率重加权 |

⇒「k=2 = Grover 一次迭代」是**修辞而非数学**——Grover 的 √N 加速来自振幅干涉，幂运算做不到。

### 发现 3（甜点）：次目标概率在 k\* = 1.88 达峰

- `P_sec`：k=1 → 0.280；**k=1.88 → 0.2972（max）**；k=3 → 0.280；k=8 → 0.117
- 「放大」不是均匀的：**中间层先受益**（最低分项衰减更快，质量重分配）
- ⇒ exp31 选 k=2 正落在次目标峰上——实验里「k=2 完成数最高、次目标推进也最高」**不是巧合**
- 熵 H(k) 单调下降（1.55 → 0.09，k=0.5→16）——k 是「行为集中度」的旋钮
- `P_last < 0.001` 从 k = 2.91 起——最低分目标「事实上消失」的界

### 发现 4：受挫语义

- 实现 `clip(0)` = **硬排除**（P=0，质量重分配）
- 「反相」的量子类比不成立（真振幅反相**不改变测量概率**——概率下降靠干涉）
- 实现效果 =「受挫 2 次 → 永久放弃」，与「重规划」逻辑自洽
- 若想要「偶尔还会想一下」（执念/遗憾感），应改用**衰减因子**而非归零

### 蒙特卡洛验证

1e6 采样 vs 解析（k=2）：max|diff| = 0.00033 < 1/√n ✓

## probe4：salience 加权 Hopfield——「低负载有害、高负载有益」的交叉结构

### 理论

W = (Σ c_m s_m s_mᵀ)/C（对角置 0），以完整模式 s_k 探测，一步局部场：

```
SNR_k = c_k (N−1) / sqrt(N · Σ_{m≠k} c_m²)
```

- **均匀权重**：SNR = (N−1)/sqrt(N(M−1))（与 c 无关——「统一待遇」）
- **加权**：SNR ∝ c_k——把统一 SNR **重分配为分层 SNR**（高的更高、低的更低）

### 分层数字（N=80，5 档 c = {0.3, 0.475, 0.65, 0.825, 1.0}，M=20）

| c | 均匀 SNR | 加权 SNR | 一步估计 Φ(SNR)^80（均匀 / 加权） |
|---|---|---|---|
| 0.3 | 2.03 | 0.86 | 0.178 / 2.6e-8 |
| 0.475 | 2.03 | 1.36 | 0.178 / 0.0007 |
| 0.65 | 2.03 | 1.89 | 0.178 / 0.091 |
| 0.825 | 2.03 | 2.43 | 0.178 / 0.545 |
| 1.0 | 2.03 | 3.00 | 0.178 / 0.897 |

### 主发现：交叉结构

MATLAB 蒙特卡洛（300 trials/点，遮 30%）：

| M | classic | weighted | 谁赢 |
|---|---|---|---|
| 5 | 0.993 | 0.833 | classic |
| 10 | 0.850 | 0.563 | classic |
| 15 | 0.450 | **0.453** | ≈ 交叉点 |
| 20 | 0.147 | 0.300 | weighted |
| 25 | 0.020 | 0.187 | weighted |
| 30 | 0.003 | 0.110 | weighted |

- **实测交叉 ≈ M=15**（α≈0.19）；WL 一阶理论交叉 = M=20（α=0.25）——**交叉带 M≈15–20**（≈经典容量线 0.138 的 1.4–1.8 倍）
- 机理：低负载时所有模式 SNR 都有余量，加权只把低 c 压下去（**纯损失**）；超负载时「把一部分推出临界带」的收益 > 「把另一部分推入」的损失（**净收益**）
- ⇒ **exp35 表里 M=10 那行（加权 0.77 < 经典 1.00）不是噪声——是交叉结构的证据**。probe4 给了它机制与坐标。

  但比理论（2.6e-8 → 0.897）**平缓得多**——遮挡拉低整体（SNR ×≈0.84）+ 异步动力学多步修复把两端压平
  ⇒ 理论给「方向与排序」，实测给「绝对值」——各司其职

## probe6：秩扫描——「高秩对话」下低秩压缩怎么退化（lmq 直觉的量化）

> 起因：lmq「张量网络压缩好像和信息的秩有关，高秩对话效果不好」——方向 ✓，量化出**三个退化信号**和一个临界点。

### 设置

K ∈ {8, 16, 32, 64, 128} 话题数 × 两种排布（block 块状 / inter 交错）；T=200, D=64, 噪声 0.3；96 query；TN 扫 r = 1..64 取最优。

### 结果表（MATLAB）

|---|---|---|---|---|---|---|
| block | 8 | 4.39 (8) | 7 | 1.000 | 0.500 | 1.000 |
| block | 16 | 2.96 (16) | 8 | 1.000 | 0.500 | 1.000 |
| block | 32 | 1.45 (32) | 15 | 1.000 | 0.500 | 1.000 |
| block | 64 | 1.07 (32) | 16 | 1.000 | 0.500 | 1.000 |
| block | 128 | 1.04 (2) | 32 | 1.000 | 0.500 | 1.000 |
| inter | 8 | 3.87 (8) | 8 | 1.000 | 1.000 | 1.000 |
| inter | 16 | 2.38 (16) | 12 | 1.000 | 1.000 | 1.000 |
| inter | 32 | 1.40 (32) | 18 | 1.000 | 1.000 | 1.000 |
| inter | 64 | 1.08 (34) | 25 | 0.958 | 0.844 | 0.958 |
| inter | 128 | 1.06 (4) | 27 | 0.802 | 0.542 | 0.802 |

### 三个退化信号（「效果不好」的精确化）

1. **断崖塌陷**：σ_K/σ_K+1 从 **4.39 → 1.04**（K=8→128）；**峰位 i\* 追踪 K**（K ≤ 32 时 i\* = K）——
   「信号秩 = 话题数」可以直接从谱上读出来
2. **最优 r 膨胀**：r\* 7 → 32（block）/ 8 → 27（inter）——**压缩率从 ~11% 崩到 ~50%**：
   还能准，但不省了（「假压缩」）
3. **准确率天花板下移**：inter K=128 时连 full 也只有 0.802（任务本身变难）；TN = full——
   无额外损失，也**没有免费空间**

### 理论（WL）

- 预测：信号带 = √(T/K) × 中心谱；中心谱 ≈ √dim·(1 ± √(K/dim))

## probe7：exp30 去重「互信息」的三层鉴定（记忆系统·去重环节）

## probe9：±1 反对称与「配对统计」——吸引子的对称结构（续 probe8）

### 数学层（WL）：反对称引理

**引理**：W 对称、零对角、sign 按「≥0 → +1」约定。则 `T(-x) = -T(x)` 在 `Wx` 无零分量处成立
⇒ **不动点成对（x ↔ −x）当且仅当 h = Wx 无零分量**（零处约定破坏反对称：sign(0)=+1，而 −sign(0) 需为 −1）。

**子网验证**（16 节点全枚举）：
- 不动点 **4/4 全配对**（min|h| = 0.086~0.114 > 0，无零 ✓）
- **2-周期只有 68/112 配对（60.7%）**——退化点（h 有零）破坏配对 ✓，引理的条件性被数据咬合

### 全网层（MATLAB，1000 异步采样）

- **639 个真不动点**（20 个非收敛被过滤）；**143/639（22.4%）有零分量** ⇒ **结构配对率 77.6%**
- **margin 中位数 0.0086**——大量不动点「贴着临界」（精细平衡类；对比子网 4 个强饱和点）
- 配对审计两口径：**结构 77.6% vs 采样 17.2%**——**差额 60 个百分点全是「采样不足」**（成员盆地小 + 盆地不对称）

### 三种统计口径（同一批 639 点）

| 口径 | AVA+DD | AVB+DB | RIV | PVC | IL2/URX |
|---|---|---|---|---|---|
| equal（as-found 等权） | 0.0383 | 0.0141 | 0.0276 | 0.0094 | −0.0125 |
| **weighted（盆地加权）** | 0.0505 | 0.0310 | 0.0558 | 0.0418 | 0.0342 |

## probe10：exp32「量子退火欲望」的机制审计——空转是唯一的罪（调度家族）

### 账本分解（Python 逐位复刻，rng 流一致）

对拍：四策略总饥饿与 exp32 基准**逐位一致**（494/1278/514/1175）；恒等式 `h_final = 252 − clip − serv_act` 残差 0。

|---|---|---|---|---|---|---|
| greedy | 494 | 166 | 250.7 | 811 | **560** | 0 |
| inertia | 1278 | 24 | 245.6 | 1152 | **906** | 0 |
| anneal | 514 | 152.6 | 250.0 | 843 | **593** | 0 |
| quantum | 1175 | 30.8 | 246.5 | 1136 | **889** | 0 |

- **实服务量几乎相同（245.6~250.7）——守恒锁死**：策略只能改「服务时机分布」，改不了总量
- **空转浪费 = 服务预算打在已清零的目标上**：占预算的 **69~79%**
- **clip = 0 全程**：`min(30)` 上限是装饰（峰值 7.2）——**dead code #1**

### 机制身份（WL）

1. **「模拟退火」= 常量 ΔE 噪声注入器**：实现 `P = exp(−0.2/T)` **与 gain 无关**（标准 Metropolis 是 `exp(−gain/T)`），
   gain 只当「>0」闸门——身份：**温度调度的固定概率切换器**
2. **「后期冻结」不存在**：T_min = **0.789**（10×0.985¹⁶⁸）——`max(T,0.1)` 是 **dead code #2**；
   P_impl 只从 0.980 降到 **0.776**——末态还有 77.6% 切换率
3. **「局部最优陷阱」不存在**：冻结区 `h_cur > 20.8` 从未进入（峰值 7.2）——真实代价是**空转窗口**
   （目标清 0 后仍被喂 ~6.25 步）——与账本 906 呼应

### 策略库对照（MATLAB，200 runs/策略）

| 策略 | hunger | vs floor(252) |

### 结构台阶的解析（~490）

- 离散时序（测量在累积后、服务前）下，间隔 k 的三角波平均 = `rate·(k+1)/2`
- 最小化 `Σ rate_i(k_i+1)/2`（s.t. Σ1/k_i = 1，Lagrange）⇒ `k_i ∝ 1/√rate_i`
- **结构下界 = Σrate_i(k_i+1)/2 ≈ 2.90/步 → ×168 ≈ 487.6**
- **四种理智策略（494/502/503/502）全部到位**——`~500 台阶不是次优，是结构最优`；**贪心已近最优**（差 1.3%）

1. **在「服务能力过剩（3.2×）」的调度系统里：唯一有害的事是「不服务」**——
   「早服务/晚服务」几乎无差；「省切换」纯属自伤（阈值单调 ⇒ 惯性思想在本参数下是**系统性错误**）
2. **exp32 排名反思**：贪心（494）在四原策略中最优；「量子退火」（1173）≈「惯性」（1278）+ 噪声——
   **隧穿 5% 没有改变主结构**（它的排序键 h/rate 本来是对的，被惯性窗口拖住）
3. **改进空间在「停止空转」，不在「更聪明的调度」**
