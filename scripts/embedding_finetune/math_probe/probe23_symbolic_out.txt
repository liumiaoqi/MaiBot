=== probe23: exp61 interference identities (symbolic) ===

--- 1. 3-node line, source at node 0 ---
eigenvalues (exact): {-Sqrt[2], Sqrt[2], 0}
p0(t) = Cos[t/Sqrt[2]]^4
p1(t) = Sin[Sqrt[2]*t]^2/2
p2(t) = Sin[t/Sqrt[2]]^4
=> interference = cross terms between eigenvalues; here beats at |lambda_i - lambda_j|

--- 2. two-source identity: p_q = p_incoherent + interference ---
residual (should be 0 for all nodes): {0, 0, 0}

interference term per node:
  node 0: 0
  node 1: 0
  node 2: 0

=> identity holds exactly; the interference term is a RE part of a product of
   two coherent amplitudes -- real, oscillatory, can be negative.

--- 3. triangle (contrast): eigenvalues {2, -1, -1} ---
p0(t) = (5 + 4*Cos[3*t])/9
=> on a degenerate/compact graph the interference pattern differs (different beat set)
