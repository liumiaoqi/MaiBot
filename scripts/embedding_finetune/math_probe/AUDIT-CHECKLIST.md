# 实验审计清单 —— 从 math_probe 十五个探针提炼

> 来源：2026-10-08 math_probe（15 探针 · 16 个 exp · 8 笔提交）。每条 `[]` 内是案例指针（见 NOTES.md）。
> 用法：**写实验前**过「设计问句」；**写完实验**过「审计问句」；写/改脚本时查「工具坑」。

## 一、写实验之前（设计问句）

1. **最坏情况语义**：空集 / 多路同发 / 边界穿越 / 零点——写下来了吗？
   [probe15：「多路同时发放」发生率 50.6% 却未定义，实现替它选了 softmax 重采样，动作分布随之漂移]
2. **参数的作用面**：拨动这个「自变量」，因变量实际改变几成？——先做因果链预算
   [probe14：换噪声源（MT→内禀），2748 次决策只有 4 次行为不同（0.15%）——干预几乎没上桌]
3. **数值可达性**：每个上限 / 下限 / 阈值，在真实数据里触得到吗？
   [probe10：min(30) 全程未触发（clip≡0）；max(T,0.1) 从不触发；「冻结区」从未进入——三处 dead code]
4. **对照的口径**：符号方向对吗（加价/减价、惩罚/补贴）？参数预算真的对齐吗？
   [probe14：滑点符号反向——「对抗」实为「补贴」；probe5：`r=15≈50%` 实际 23.6% 且公式漏 V_r]
5. **统计口径**：结论用加权/等权/规范化——换一种会不会翻符号？
   [probe9：同一批不动点，equal≈0 / weighted 全正 / canonical 全负（第三种的负号是选择偏差）]
6. **对照点的密度**：单点对照会掩盖交叉结构——至少扫 3~5 个点
   [probe4：只看 M=10 会以为加权有害，扫开才见「低负载有害 / 高负载有益」的交叉带]
7. **标度实验用嵌套系统**：跨规模的比较，样本必须逐层包含
   [probe13：各 n 独立随机图时趋势全乱（1.72→1.88→0.33→0.72）；换「母图诱导子图」立刻干净]
8. **能用全枚举就用全枚举**：参数空间不大时，全枚举 > 抽样
   [probe2：C(30,4)=27405 组分布十秒跑完——「策略无关」从抽样观察升格为全空间定理]

## 二、写完实验之后（审计问句）

9. **数学身份**：核心函数的「名字」是真的吗？闭式化看看
   [probe3：「Grover 式放大」= softmax 温度采样；probe7：「互信息」= 共现词的加权计数]
10. **对拍分辨率 ≤ 输出分辨率**：文本往返精度是第一陷阱
    [probe1：F12.6 量化造成 4.99e-7 假差异；提到 F22.15 后归零]
11. **小样本结论要扩样**：N 小时浮起来的信号，N 大时未必在
    [probe9：RIV 0.40（N=46）→ 0.03–0.06（N=639）——小样本涨落，未能保住]
    ⚡ **先估再跑**：效应量 vs 噪声尺度——noise-dominated 系统里 n=1 的 A/B 无效
    [probe19：挪墙效应 ~30% vs 组内波动 ~300%——方向信号在、统计不可分；需 n≥5-10 或降噪评估]
12. **「收敛/冻结/陷阱」这些词要验**：调用返回时真的在不动点吗？能量真在降吗？
    [probe8：95% 的「收敛状态」不是不动点；probe10：「后期冻结」不存在（末态切换率仍 77.6%）]
13. **动作源与决策源分离**：噪声加在哪一层？加在公共项上等于没加
    [probe14：同一个 n 加三路 ⇒ 平移不变；probe15：sin² 三路测量被 e^{ps} 压平到 2.72 倍对比度]
14. **敏感性维度**：单点数值全对 ≠ 模型没问题——扰动「分布 / 时机 / 规模」才有发现
    [probe1：31 天留存只依赖次数不依赖分布；probe6：秩升高时三重退化]

## 四、本机工具坑（速查 · 均为实证）

- **Wolfram**：`D` 是保护内置符号（改名 `dim`）；`===` 跨类型判等（`1 === 1.` 为 False，数值用 `==`）；`RandomChoice[list]` 直接给标量
- **MATLAB**：分支判断别用 `strcmp` 配带后缀的名字（用 `startsWith`）；`numel(矩阵)` ≠ 行数（用 `size(I,1)`）；`roots` 要降幂系数
- **ctypes**：裸文件名不搜索 CWD（须带路径）；`bind(c)` 无 `value` 的标量按引用传参
- **Python / heredoc**：双反斜杠字面量会被折叠（用 `chr(92)` 构造）；`python -c "..."` 里反引号被 bash 吃掉（改用 heredoc）
- **进程外工具**：`gfortran` 的 DLL 用 `-static-libgfortran` 时可能引入 UCRT 私有 apiset 依赖
- **仓库纪律**：工作区会被外部格式化器覆盖——**改完立刻提交**；提交门会自动修 CRLF / 末尾空行等机械项
