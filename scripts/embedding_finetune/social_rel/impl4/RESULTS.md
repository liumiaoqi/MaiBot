## s5.2（同日）：扩散激活 × confidence 端到端排序

**问**：把 s5.1 的扩散激活（t≈4）接进排序评分（×痕迹派生 conf），与现状 2-hop 对比。

| 臂 | nDCG@5 |
|---|---|
| a. base 2-hop | **0.7467** |
| b. diffusion t=2 / t=4 / t=8 | 0.4790 / 0.3428 / 0.2148 |
| c. diff×conf κ=0.0 / 0.3 / 0.5 / 0.7 / 0.9 | 0.2677 / 0.2971 / 0.3287 / 0.3213 / **0.3571** |

1. **P1 否**：扩散在「小 d 优先（2^-d）」的排序里输给 2-hop——**这是口径效应，不是扩散无用**：
   2-hop 枚举本身就是该指标的 oracle 近似（它按距离排）；扩散的价值在 s5.1 已证的「远端可达」，
   用「越近越好」的指标评它 = 让它去跑别人的赛道。
2. **P2 是**：κ=0（痕迹无真值）时 conf 不帮忙 ✓——负对照成立。
3. **P3 差 0.014（κ=0.5）→ 过零扫描：κ=0.9 时 0.3571 > 0.3428，过零点约 κ≈0.8**——
   conf 增量方向与 s3/s4 一致（收益 ∝ ρ(痕迹,真值)），要真值够强才翻正。

**结论（对线）**：扩散与近邻排序**不是竞争关系**——正确组合 = 近邻优先（现状）保留 +
扩散作为**远端补充通道**（探索位），confidence 的用武之地在扩散通道的权重上。

**工程插曲（如实）**：v1 的三档 t 结果完全相同（0.0494）——自查发现特征向量投影误写为
特征值点积（`vals[0].T` vs `vals[1].T`），修后 t 梯度立刻正常。**「同值三连」是 bug 的第一信号。**

**产出**：`impl4/rank_diffusion.py` + `rank_diffusion_output.txt`
