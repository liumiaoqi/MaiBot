## 〇、三句话

1. **问题**：MaiBot 的「关系强度」`confidence` **恒为 1.0** ⇒ 排序接线（`graph_relation_recall.py:119-128`）、双护栏（`confidence_guard.py`）、
   CA 的实验证据（nDCG +5-20%）**全都就绪**，但整条链路**在真实数据上是恒等变换**。
2. **但顺序不能反**：实测 **收益 ∝ ρ(痕迹, 真值)，ρ<0.36 为负**；真库**没有真值**；且 **无真值时把覆盖率抬到 75% 会把伤害放大 3.7×**（§4.5）。
3. **所以本次只申请两件最小的事**：
   - **S1** 补一个**上界**（纯缺陷修复，**零语义变化**）；
   - **S2** 用 **47 条 `is_pinned`** 做一次**有界**的真值种子实验（范围、判据、回滚都写死）。

## 一、S1：补上界（缺陷是真的 —— 我亲自核过代码）

| 项 | 内容 |
|---|---|
| 位置 | `src/A_memorix/core/runtime/services/v5_memory.py:91` `adjust_relation_confidence` |
| 现状 SQL（**我核过**） | `SET confidence = MAX(0.0, COALESCE(confidence, 0.0) + ?)` ⇒ **只有下界，没有上界** |
| 调用方（**我核过**） | `v5_memory.py:125` reinforce `+0.5·strength` · `:136` weaken `−0.5·strength` · `:147` forget `−2.0·strength` |
| 后果 | `confidence` 现为 **1.0** ⇒ **第一次 `reinforce` 就变 1.5** ⇒ ⚠️ **超出下游 `unified_profile_service.py:115` 假定的 `[0,1]`** |
| 另一条路（据 `impl3`） | `remember_forever` → `relation_store.py:594` `confidence = MAX(confidence, boost_weight)`，`boost_weight = max(prune_threshold, 0.1) = 0.1` ⇒ `MAX(1.0, 0.1) = 1.0` **恒空操作** |
| **改法（一行）** | `SET confidence = MIN(1.0, MAX(0.0, COALESCE(confidence, 0.0) + ?))` |
| **判据** | ① 现有 184 条**仍全 1.0**（行为不变）② 任一写路径之后 `confidence ≤ 1.0` ③ 复跑 `impl3/wiring_plan.py` 的 2×2 **不受影响** |
| 风险 / 回滚 | **无风险**（缺陷修复，非语义变更）· 回滚 = 一行还原 |

> 为什么先做它：它**不依赖任何 ρ 假设**，也不会让任何现有行为改变 —— 是"**把路修平**"，不是"改目的地"。

## 二、S2：有界的真值种子实验（**47 条**，不是全部 184 条）

**真值用哪个**（据 `impl3` 的通道体检，我复跑一致）：

| 通道 | 覆盖 | 在检索环内？ | 判定 |
|---|---|---|---|
| **`is_pinned`** | **47/184** | **否** | ✅ **唯一可用**（显式动作写的 —— ⚠️ 但是"人点的"还是"agent 自主判断"，**本线无法证明**，见 §五） |
| `last_reinforced` | 22/184 | **是** | ⛔ 不能用 —— **写入者就是被评估的检索环** ⇒ 自证 |
| `access_count` / `last_accessed` | 0 | — | ⛔ 空 |
| `confidence` | 184/184 | — | ⛔ 常数（零信息） |
| `memory_feedback_*` | 0 | — | ⛔ 0 行 |

**做法（两步，都是数据面，不改代码逻辑）**：
1. **改列默认**：`confidence` 默认 `1.0 → 0.5`（只管**将来**新行）；
2. **迁移存量**：**把非 pinned 的 137 条从 1.0 降到 0.5**；**pinned 的 47 条保持/回填 1.0**。
   ⇒ **天然对照组**：47 条有真值 vs 137 条无真值，**同一张表、同一套排序**。

**判据（缺一不可，任一不过就回滚）**：
1. 真库可查：`COUNT(DISTINCT confidence) = 2`（1.0 / 0.5）；
2. **离线复刻**（用 `impl2` 的方法）：`sim × confidence` 排序相对"常数权重=现状"，
   **Δhit@5 与 Δsel1 同时 > 0**（两个数同时给，audit 的硬约束）；
3. ⚠️ **护栏不被误触**：新值不得让 `ConfidenceGuard` 判"反对齐"降级（否则等于白改）；
4. 若不显著 ⇒ **回滚并如实记负结果**（**不许**把"不显著"写成"有效果没测出来"）。

**回滚**：先做真库快照；回滚 = 一条 `UPDATE`（把两档还原为 1.0）+ 默认值还原。
