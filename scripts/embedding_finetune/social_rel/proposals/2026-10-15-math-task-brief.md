1. **前沿 → 本研究的映射无法提前预知** ⇒ 找研究不能只靠目标驱动——
   要有一定**随机性 / 碰运气**的成分（随机漫游机制，见 T7）。

   每份笔记固定**双栏**：① 可迁移点 ② 哲学 · 方法 · 方向观察。
3. **我们不是为了论文** ⇒ 所有随机性实验一律使用**硬随机器**，且**大量重复**（§三 硬约束 6；已装备：`math_probe/hard_random.py`，probe27 范式）。
4. **分析用 R 软件**（本机已装 R 4.6.1）；计算工具灵活组合（§三 硬约束 7）。
5. 一切产出的最终指向不变：**自生长 + 抵抗力 / 恢复力 + 有机组合**。

## 三、硬约束

1. **三铁律**（本线）：预登记判据 · 独立证伪 · 真库零改动。
2. 本轮全部「读 + 写笔记」：**不动代码**；产物一律标注「理论对照，未实现」。
3. **诚实纪律**：结论可以是「不适用 / 门槛太高」——不许硬凑。
4. 复算纪律（本线 §9）：涉主量的笔记配 x 装置，编号与既有序列连续。
5. 每份笔记必须**指回原始论文**（族号 + 标题 + 仓库路径），便于第三方复核。
6. **随机源与重复纪律（lmq 定）**：所有随机性实验——
   ① **硬随机器 = 计算机的硬件真随机**（lmq 明确）——本线**已有现成实现，直接沿用、不重造**：
      `math_probe/hard_random.py`（RDSEED / RDRAND **机器码注入直读**、零编译依赖；
      本机 RDSEED 被环境挡 ⇒ 自动回退 RDRAND——现场实测 1.6 μs/draw · 2 万次零失败零重复 ·
      popcount 31.98 / low-byte 127.0）。运行范式照 **probe27**：**P 固定**（对照 / 调试）＋
      **H 硬件**（正式主源），每 run 一个硬件种子、**种子全记录入库**。
      ⚠️ OS 层 CSPRNG（`secrets` / `os.urandom`）与语言级 PRNG **不算**硬随机，不得作正式随机源
      （对照臂可以）；正式实验不得用固定伪随机种子——我们不为论文，不背"固定种子可复现"的惯例
      （前例：probe27 · exp23-24 · exp36）；若 audit 报 unavailable（全部硬件源被挡）：
      如实上报、暂停该实验，**不得静默降级**为 OS 层。
   ② **大量重复**：单次或少量跑不算数——重复规模先做量级估算再定，判据 = 关键统计量
      （均值 / 方差 / 分位数）随重复数**收敛**；量级参考 probe27（6 尺寸 × 96 runs = P48 + H48）；
      方差估计参考 exp23-24 教训（采样不足会低估 30–40%）；重复结果交 R 做分布与方差分析。
   调试可暂用固定种子（P 臂），但产物必须标注「调试」、不得作结论依据；随机源、重复次数与时刻写进产物留痕。
7. **分析工具纪律**：随机性实验的**统计分析用 R**——本线**已有 R 管线先例**（probe27：base R 零依赖
   的聚合 → 峰定位 → FSS 拟合 → 图；x78 与 WL 独立实现逐位一致）：新分析沿用该形态（Rscript · 本机 R 4.6.1）；
   计算工具按任务**灵活组合**——Wolfram（符号 / 复算）· Python（仿真）· R（统计）· 本线 x 装置。
