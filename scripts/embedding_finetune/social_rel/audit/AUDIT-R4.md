## 1. 反例① —— s3 正增量的独立复现（κ=0.5, σ=0.35）

```
常数 conf: hit@5 = 4.9129 | derived: 4.9062 | 增量 = -0.0067
```

**读法**：本口径未复现 s3 的 +0.0467。但注意 baseline 已达 4.91/5（天花板），
且 conf 采用乘法（未覆盖压 0.3）会扭曲 sim 排序——净效应为负≠s3 结论被推翻（见 §5）。

## 2. 反例② —— break-even κ 扫描

```
κ=0.0 −0.0087 | κ=0.1 −0.0084 | κ=0.2 −0.0078 | κ=0.3 −0.0073
κ=0.4 −0.0071 | κ=0.5 −0.0067 | κ=0.6 −0.0064
```
全网格恒负、无过零点——s3 声称的 κ*≈0.3 在本口径下不可见（同因于 §5 的天花板效应）。

## 3. 反例③ —— σ_sim 压力测试（s3 声明 σ=0.35 是假设）

```
σ=0.20 增量 −0.0022 | σ=0.35 增量 −0.0067 | σ=0.50 增量 −0.0133
```
**方向稳定（全负）但幅度随 σ 单调恶化（6×）**——s3 的「σ 只影响 sim 精度、不影响增量比较」
仅在**同一 σ 内比较**的语境下成立；跨 σ 的结论外推不安全。

## 4. 反例④ —— 顺序陷阱（s4）

```
κ=0：cover 12% 增量 −0.0087 → cover 75% 增量 −0.0264 | 伤害放大 3.05×
```
**方向与量级独立复现**（声称 3.7×）——**s4 的核心结论「先接 record_access 会把事情弄得更糟」
在独立实现下稳健**。这是本报告（R4）最扎实的产出。

## 5. 自我审计：为什么 ①② 不能作为对 s3 的证伪

差异清单（自实现 vs s3 口径）：
1. **指标定义**：本实现用 hit@5（"相关"= rel>中位）；s3 用 cov1/sel1（定义见 impl/baseline.py）
2. **conf 映射**：本实现用 sigmoid(t)；s3 用「时效+支撑度」合成（rec_norm/sup_norm/alpha=0.5）
3. **世界生成**：本实现 rel~N(0,1)、sim=rel+N(0,σ)；s3 的池按查询组织、可能含更弱的信息结构

**天花板效应**：baseline 已 4.91/5——改善空间 ≤0.09/5，乘法 conf 的排序扭曲占主导。

**正确做法（下一轮）**：用 s3 的生成器/指标做**同口径对拍**（自实现但参数逐项对齐），
或请实现者提供**最小复现脚本**——在拿到同口径数据前，R4 对 s3 只能记「未复现、不推翻」。
