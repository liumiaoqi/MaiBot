## 一、SBM 的精确可恢复阈值（族 229）——「分类能涌现到什么程度」的数学版

- **定理（三社区稀疏 SBM）**：组内率 a、组间率 b、平均度 (a+2b)/3 > 1 的对称三社区随机块模型——
  **弱恢复恰好可能当且仅当 `(a−b)² > 3(a+2b)`**；阈值处及以下**信息论上不可能**；
  以上可在 O(n log n) 内达到。（出自族 229 的"三态对称信道"篇——它是该族 SBM 推论的直接来源。）
- **配套件**：Kesten–Stigum 精确重建阈值 `dλ² > 1`（树上广播，均含 equality 处不重建的加强）；
  四态 Potts 的 **L³ capacity 判据**（`λ^{-2|e|}` 边阻下的容量为正 ⇔ 可重建——不依赖树的规则性）。
- **为什么关心**：「分类从关系中涌现」此前只能"跑个聚类看看"；这族定理把问题**前置**为
  「图里有没有那个信息」——先判信息，再谈算法。

## 二、映射：SBM ↔ 我们的关系图

| SBM 要素 | 我们的对应 | 怎么估 |
|---|---|---|
| 节点 | 实体 / 参与者 | 图上节点（现有 GraphStore） |
| 边 | 关系 / 共现 / 共激活边 | 现有边（+ 未来 0004 的真值回路边） |
| 社区标签 | 潜在类别（分类涌现的目标） | 未知——正是要求的东西 |
| 组内率 a / 组间率 b | 类内 / 类间连接率 | **可测**：选候选分组 → 统计组内/组间边密度（常规化到 n） |
| 平均度 | 图平均度 | 可测 |
| 信道参数 λ | 边上的"信号强度"（关系强度/confidence 的类比） | 待定义（对应关系：边越强 → 越像"可靠信道"） |

## 三、可测预言的形态（怎么用）

1. 选候选分组（现有类别体系，或嵌入聚类的结果）；
2. 在**真图**（只读）上估 a、b、平均度；
3. 代入 `(a−b)² > 3(a+2b)` 判定：
   - **成立** ⇒ 类别**可恢复**，且理论上存在 O(n log n) 恢复法——"没涌现"是**算法问题**；
   - **不成立** ⇒ **信息论上不可能**——"没涌现"不是算法问题，是**图里没有那个信息**，
     再好的聚类也是幻觉（此为硬结论方向）。
4. 意义：把 LT-2 的验收从"涌现成功没"升级为"**先判信息在不在**，再谈实现"。

⚠️ **前置缺口（写进附录的诚实句）**：SBM 定理的前提含"平均度 > 1 的稀疏随机图"。
以最近可查的图实况为参照（8-31 快照：重建后 27597 节点 / 76 边）——**当前图远不到该前提**
（度 ≪ 1）。⇒ 映射的第一步不是算阈值，而是**先把图长起来**（这正是 0002 重建 / 0004 真值回路 /
共激活边在补的工程缺口）。阈值定理在"图有了边"之后才是判据。

## 四、渗流（族 213/214）——「韧性」的语言

- 族 213：临界渗流在临界概率处**无无限簇**（Benjamini–Schramm 临界性猜想，quasi-transitive 图全类）；
  族 214：非唯一性（p_c < p_u 区间里无限多个无限簇共存）。
- 对我们的用法：给「抵抗力 / 恢复力」一个**可测的实验语言**——例如：
  "随机删 x% 边（或模拟遗忘/清理）后，检索链路仍可达的比率曲线；碎裂突变点在哪个 x"。
  与方向 E（扩散检索）共用同一理论尺度：**次临界图上的扩散会快速熄灭**——
  「删除实验」与「扩散检索」是一条理论线上的两个操作。

## 五、边界与裂缝（诚实节）

1. SBM 的均质随机假设 ≠ 我们的图（语义边、度分布不均、可能重尾）——**"可能"侧的阈值别当保证用**；
2. 但**"不可能"侧**（信息论下界）在更广的模型类里稳健——**用它做排除法（"别指望恢复"）比做保证安全**；
3. 未做：真图上的 a/b 估计（需选分组 + 真库只读）——列为后续（可作 LT-2 开工第一步）；
4. λ 与 confidence 的对应关系未定义——是映射里最软的接口，标注待议。
