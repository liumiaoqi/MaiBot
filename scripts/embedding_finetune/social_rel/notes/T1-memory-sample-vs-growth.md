## 〇、对照的两问（任务书原文）

a) s6.1 的设置与下界模型相差哪几条假设；
b) 把 s6.1 的反馈批量折算进该框架：处于下界哪一侧、差几个量级。

## 一、两边各是什么

- **下界框架**：状态 ≤ Ad² bits、单遍读取无噪声观测 y=⟨x_t,s⟩、恢复球面信号（角误差 ε、成功 2/3）——
  主定理 **T ≥ c_A·d·ln(1/ε)**：把噪声去掉也省不掉样本——**瓶颈是记忆/信息效率本身**。
- **s6.1（v7 已判决 / v8 在测）**：120 节点（100 真 + 20 诱惑）× 32 维；每节点一对整数计数 (pos,tot)，
  conf=(pos+2)/(tot+2) 乘进 top-5 排序；反馈按批注入（0→500 条）、60 query 池、all 口径；
  质量参数 pu；输出 = 命中率曲线。**v7 平台**：pu0.8→0.873 ｜ 0.59→0.800 ｜ 0.0→0.500（单调，信号纯度响应）。

## 二、假设差异（a）——相差 5 条，不能直接套用

| # | 下界框架 | s6.1 实际 | 差异 |
|---|---|---|---|
| 1 | 恢复连续方向（球面） | 校准离散配对的置信度（排序质量） | 估计 vs 组合校准 |
| 2 | 无噪声精确观测 | 伯努利反馈（pu<1，且为结构性"诱惑"噪声） | 观测有噪 |
| 3 | 单遍、不可回头 | 多遍：同一 query 反复出现（可复用） | 非流式一次性 |
| 4 | 状态有显式 bits 预算 | 状态 = 整数计数（无显式预算，但天然有限） | 预算语义不同（量级见 §三） |
| 5 | 输出 = 终态估计 | 输出 = 连续行为指标（命中曲线） | 验收对象不同 |

## 三、折算（b）——量级粗对（x79 复算；标"量级"不标"定理"）

最自然折算：**d = 嵌入维数 = 32**；**T = 500**。

- **状态侧**：120 节点 × 2 计数 × 9 bits（计数 ≤500 ⇒ ⌈log₂500⌉=9）⇒ **M = 2160 bits**；
  **M/d² = 2.11**（x79）——恰落在框架的 **"Ad² 尺度带"附近**（A 为固定常数）。
- **样本侧**：d·ln(1/ε)（ε=0.1）= **73.68**；T=500 ⇒ **T/(d·ln) = 6.79**；
  比照下界常数带 c_A=2~4（147 / 221 / 295）：**T / 下界 = 3.39 / 2.26 / 1.70**。
- **读法（三句，防过度解读）**：
  1. 不在"明显欠记忆 / 欠样本"区——两侧都在理论关注的量级带内或之上；
  2. 但 500 条**远非"信息饱和"**——对 32 维而言这是"必要量级"×1.7–3.4，不是宽裕；
  3. 假设错配（§二）使以上**只作量级参考**，不能当定理套用。

## 四、对 s6 的两个可用推论

1. **排除法**："s6.1 平台 = 记忆 / 样本不够"的解释缺乏本框架支持——两量级都在带内；
   平台更可能成因 = 信号结构（v7/v8 方向：平台 ≈ f(信号纯度)，三臂数字吻合）。
2. **一个便宜的判决实验（建议，未做）**：样本"贴必要量级"而非饱和 ⇒ 加**高样本对照臂**（500→2000/5000）：
   - 平台不动 ⇒ 再添一条"样本维度可排除"的硬证据（v8 论断加固）；
   - 平台抬升 ⇒ v8"必然性"需缩范围（部分成因是样本）。
   - 成本：`growth_curve.py` 的 BATCHES 元组一处改动（分钟级）。
