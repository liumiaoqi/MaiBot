## 一、六条可直接引用的结论

1. **我们的图是"慢松弛"图**：谱隙 gap = **0.0441**，同度随机图（ER）0.3545——**慢 8 倍**（语义簇结构的"摩擦"）。
2. **没有 cutoff**：TV 曲线渐进型（(t90−t10)/t50 = 2.75）——扩散要 **t90 ≈ 26–28 步**才混匀。
   ⇒ **impl4 的扩散工作点 t≈4 ≈ 15% 的 t90——工作在"未铺开"区**（"远端可达 vs 近端占比"权衡的动力学根源）。
3. **"先死后塌"（probe29/29b）**：**动力学退化在前**（70–75% 删除时扩散已不可达）、**结构崩塌在后**（80–85%，p½ 首破档=85%）。
   **结构 80% 完好时，扩散已经死了** ⇒ 用节点/边数评韧性会**严重高估**；体检看 t90 / 谱隙。
4. **"均匀 vs 结构"的效应是分区的**（两例反转）：低删除区结构打击（度序）更伤连通；高删除区（85%+）**随机"均匀剪薄"崩得更狠**（0.148 vs 0.415）。
   机制（probe30）：**同样的残余平均度（1.276）、两个世界**——结构打击 → "巨核+荒地"（**可预判**）；均匀损耗 → "**临界彩票**"（0.06–0.27，std 0.078）。
5. **bulk 谱统计 ≈ GOE**（r=0.5231 vs GOE 0.5307）：局部谱像随机矩阵、全局松弛却慢——**两个尺度是两回事**。
6. **恢复的代数（probe31）**：① **精确逆操作无痕**（全恢复 / 逆序恢复 Δ=0.0000——**回滚正当性实锤**）；
   ② **部分恢复 = "史的重写"**——同 50% 删除量，"崩过再救"的图比"直接停在 50%"的连通性 **+10.6pp**（0.9936 vs 0.8880）：
   恢复把靶向史洗成均匀损耗——"疤痕"是一种**新的幸存者**；③ **"结构复活 vs 动力学落后"**——S 回来了、t90 没回来
   （41.5 仍停在随机删的 42.2 旁）——"先死后塌"的对偶。

## 二、可直接接入的三条动作（建议）

1. **把扩散工作点挂到混合时间上**（impl4 / 方向 E）：t≈4 目前是拍的常数——建议改成"**t = α·t90**"（α≈0.15）形式，或至少在报告里标注 **t/t90 比值**——让工作点有坐标，口径可迁移。
2. **清理 / 衰减策略评测换指标**：任何"删东西"的方案（记忆清理、边裁剪）先测 **t90 / 谱隙**，再看结构数——"先死后塌"意味着结构指标会**漏报**。
3. **真库图同管线体检** ✅ **已跑（2026-10-15 · `probe38/38b`）**：共现图 **k̄=18.38 · S=0.95（主分量 25691）· L-gap=0.0067 · t90=97.5**——
   **真库图比合成图慢 3–7 倍**（gap 小 6–7× · t90 慢 3.5×）⇒ 扩散工作点（t≈4）在真库图上距混合**仅 ~4% t90**（比 kNN 的 15% 更"未铺开"）；
   ⚠️ 口径：L-gap（对称归一化，最大分量内）与 probe28 的 P-gap 同族非同数；GOE-r 因全谱不可及未做（详见 NOTES probe38）。
4. **回滚 / 清理策略的判据（probe31）**：回滚场景**必须精确逆操作**（无损）；任何"有损后再补" = **换图**（史被重写）——
   "清理过的库与没清理的，同密度、不同体质"；若确要"洗史"（抹掉结构性损坏痕迹），可研究"大删 + 有控制恢复"，
   但预期要付 t90（动力学体质）的代价。

- 对象是**合成 kNN 图**；真库图（8-31 快照：76 边）远未到可用密度——**等 0002 / 0004 把图养起来**再跑。

- "反转"两例均为**单图实证**；probe30 的机制解释成立，但未做多图泛化。
